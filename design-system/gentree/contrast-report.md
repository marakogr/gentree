## Focus visibility

Focus is never removed. Swiss uses a single indicator:

```css
:focus-visible {
  outline: 2px solid var(--ring);
  outline-offset: 2px;
}
```

- Ring vs canvas / surface / sunken / selected row: 6.00 / 6.45 / 5.47 / 5.32:1
  in light and 13.02 / 12.09 / 10.78 / 10.29:1 in dark. All pass 3:1.
- Fluent components keep their own token-driven inner indicator, now pointed at
  the Swiss `colorStrokeFocus2` (`#0b6577` light, `#8ce6f7` dark). The Swiss CSS
  adds the 2px outer ring to native `input`, `select`, `textarea` and `button`
  (`outline-offset: 1px`, so the ring hugs the field border instead of floating
  over the label).
- `outline-offset: 2px` keeps the ring outside the control's own 1px border, so
  it stays visible on inputs, chips and table rows without changing layout.
- On a row or card the ring is drawn with `outline`, not `box-shadow`, so it
  follows the square corner and never shifts content.
- The sidebar splitter (`role="separator"`, arrow keys) draws the ring inward
  (`outline-offset: -1px`) because the handle is only 8px wide.
