# Родственные связи

## Модель данных
Хранятся связи `PARENT_CHILD`, `ADOPTIVE_PARENT_CHILD` (родитель → ребёнок),
`SPOUSE`, `PARTNER` (симметричны). Братья/сёстры **не хранятся**: вычисляются через общих родителей.

## Алгоритмы
- **Родители/дети/супруги:** `get_person(...).relationships`.
- **Братья и сёстры:** получи родителей, затем детей каждого родителя; общий один родитель →
  единокровные/единоутробные (по полу общего родителя: общий отец — единокровные,
  общая мать — единоутробные), оба → полнородные. Усыновлённых отмечай отдельно.
- **Предки/потомки по поколениям:** итеративно `get_person` по связям вверх/вниз.
  Ограничивай глубину (по умолчанию 3 поколения) и число вызовов; спроси, продолжать ли.
  Для людей используй `get_ancestors(personId, generations)`; для событий собери id из графа
  и вызови `get_timeline(personIds: [...])`. Помни: это события, а не граф людей.
- **«Кем мне приходится X»:** найди путь между двумя персонами через общего предка
  (подъём от каждой до общего предка), определи степень и линию. Пользователь = опорная
  персона; если неясно, кто он в дереве — спроси.

## Термины родства (русский)
- По прямой линии: родители, дед/бабка, прадед/прабабка, прапрадед…; внуки, правнуки.
- Боковая: брат/сестра; племянник/племянница; дядя/тётя; двоюродные (общий дед),
  троюродные (общий прадед); двоюродный дядя/тётя (брат деда/бабки).
- Свойство (через брак): тесть/тёща (родители жены), свёкор/свекровь (родители мужа),
  зять (муж дочери/сестры), невестка (жена сына; по отношению к её родителям — сватья/сват),
  сноха (жена сына — со стороны свёкра), деверь (брат мужа), золовка (сестра мужа),
  шурин (брат жены), свояченица (сестра жены), свояк (муж сестры жены), сватья/сваты
  (родители супругов друг для друга), отчим/мачеха, пасынок/падчерица.
- Названое/духовное: крёстный/крёстная, крестник — только если это записано ролью события.

## Правила
- Вывод о степени родства помечай как вычисленный и показывай цепочку:
  «Иван → отец Пётр → отец Семён (общий дед) → …».
- Нет родителей в дереве ≠ «родителей не было». Говори «в дереве не указаны».
- Не объявляй людей родственниками по совпадению фамилий.
- Циклы и противоречия (человек сам себе предок) — сообщи как проблему данных, см. `data-quality-audit`.
- `SPOUSE` и `PARTNER` различай; бывших/действующих супругов определяй только по явным данным
  (событие развода и т. п.), иначе не утверждай.
