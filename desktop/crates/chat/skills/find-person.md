# Поиск персоны

## Алгоритм
1. Выдели из фразы: имя, фамилию, отчество, девичью фамилию, родственную роль («бабушка по маме»),
   годы, место.
2. `search(query, types:["person"])`. Запрос — самое информативное слово/пара слов
   (минимум 2 символа). Сначала фамилия + имя, затем варианты.
3. Если результатов 0 — повтори с вариантами (ниже). Не более 3–4 попыток.
4. Если кандидатов несколько — **не выбирай молча**. Покажи 2–5 кандидатов с различающими
   признаками (годы жизни, место, отчество) и спроси, кто имеется в виду.
   Исключение: пользователь задал признак, однозначно отсекающий остальных.
5. Для выбранного кандидата — `get_person`, если нужны детали.
6. Много страниц — используй `cursor` из ответа, не более 2–3 страниц без согласия пользователя.

## Варианты написания (русский контекст)
- Е/Ё, И/Й, дореформенные и диалектные формы (Фёдор/Федор/Теодор, Иван/Ивон/Йоган).
- Уменьшительные: Саша/Александр, Маша/Мария, Ваня/Иван, Катя/Екатерина.
- Женские формы фамилий: Иванов/Иванова; девичья фамилия — это имя с `nameType: BIRTH`,
  фамилия в замужестве — имя с `nameType: MARRIED`. Поля `lastName`/`maidenName` в desktop-модели нет.
- Отчество: Петрович/Петровна/Пётр (по отцу).
- Транслитерация: Petrov/Петров, Schmidt/Шмидт, разные системы.
- Опечатки и сокращения из документов («Алексѣй»).

## Правила
- Однофамильцы и тёзки — норма (в семье часто называли в честь деда). Различай по датам.
- Искать «бабушку»/«дядю» без имени можно только через известную опорную персону:
  найди опору → `get_person` → связи (см. `family-relations`).
- Пустой результат: скажи, что искал, и предложи уточнить (другая фамилия, год, место).
  Не утверждай, что человека нет в дереве, если поиск полнотекстовый и мог не сработать на форму слова.
- Тип `event`/`source` включай, если вопрос про событие («свадьба в 1912») или документ.

## Формат
Один кандидат: имя, годы жизни, что известно кратко.
Несколько: компактный список «ФИО — годы — место/опорный признак» + уточняющий вопрос.
