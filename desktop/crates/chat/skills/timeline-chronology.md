# Хронология

## Выбор выборки для `get_timeline`
| Вопрос | Как вызвать |
|---|---|
| вся история дерева | `get_timeline()` |
| жизнь одного человека | `get_timeline(personIds: [personId])` |
| события предков | `get_ancestors(personId, generations)`, затем `get_timeline(personIds: [...])` |
| события потомков | обойди потомков через `get_person`/`get_kinship`, затем `get_timeline(personIds: [...])` |
| всё в одном месте | `search(query: place, types: ["event","person"])`, затем `get_timeline(personIds: [...])` |

Период — `from`/`to` (`YYYY-MM-DD`, интервал `[from,to)`). `includeUndated: true`, если важны
события без даты (или чтобы честно сказать, что они есть). Страницы — `cursor`; `limit` ≤ 200.

## Алгоритм
1. Выбери выборку и период; если вопрос «что было в 1941» — `from=1941-01-01`, `to=1942-01-01`
   (интервал `[from,to)`).
2. Получи события; при необходимости `get_event` для деталей.
3. Отсортируй по дате, события без даты вынеси отдельным блоком.
4. Покажи таблицей: дата (с точностью) — событие — место — участники.

## Возраст и интервалы
- Возраст считай только при известных датах рождения и события; учитывай точность:
  при точности YEAR возраст «около N» / «N–N+1».
- Не округляй молча. Если точность DAY/MONTH разная — укажи диапазон.
- Разницу между событиями (брак → рождение ребёнка) считай так же и помечай как вычисление.

## Историческая привязка (вне дерева)
Можно кратко соотнести с общеизвестной историей (войны, революция, голод, эпидемии,
переселения) как гипотезу: «в это время…, возможно, объясняет…». Помечай «вне дерева»,
не превращай в факт о конкретном человеке. Для спорных/точных исторических сведений
предложи проверить источник.

## Правила
- Не вставляй выдуманные даты; события с `UNKNOWN` — в блок «дата неизвестна».
- Если выдача пагинирована и не вся — скажи.
- Очень длинная хронология — группируй по десятилетиям/поколениям.
