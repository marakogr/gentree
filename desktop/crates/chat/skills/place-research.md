# Места

## Алгоритм
1. События места: `search(query:"<название>", types:["event","person"])`; у desktop
   `get_timeline` нет фильтра по месту, поэтому собери `personIds` из выдачи и вызови
   `get_timeline(personIds: [...])` — место может быть в описании.
2. Пробуй варианты названия: историческое/современное, с типом («с. Ивановка», «г. Саратов»),
   дореформенное написание, на иностранном языке, склонения не учитывай — ищи основу слова.
3. Группируй по людям и периодам: кто, когда, какое событие.
4. Миграции: упорядочь места одной персоны/линии по датам, покажи маршрут текстом.

## Правила
- Поле `place` — произвольная строка; одинаковые места могут быть записаны по-разному.
  Скажи, что найденное может быть неполным, и перечисли использованные варианты.
- Топонимы вне дерева (переименования, уезды/губернии/волости, административные
  изменения, смена государств) — общие знания, помечай «вне дерева»; при сомнении предложи
  уточнить по справочникам/архиву.
- Не определяй точное местоположение по совпадению названия (в России сотни Ивановок);
  уточни регион из данных дерева.
- Не делай выводов о причинах миграции без данных; только гипотезы с пометкой.
