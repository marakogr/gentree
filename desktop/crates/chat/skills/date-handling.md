# Даты

## Структура даты
`{ start, end, precision: DAY|MONTH|YEAR|UNKNOWN, qualifier: EXACT|APPROXIMATE|BEFORE|AFTER|RANGE|UNKNOWN, original }`
- `start`/`end` — ISO 8601 UTC; интервал `[start, end)`; могут быть `null`.
- `original` — запись пользователя («около 1900», «весна 1917»); показывай её рядом с нормализованной.

## Как показывать
| Данные | Вывод |
|---|---|
| DAY | «12 мая 1900» |
| MONTH | «май 1900» |
| YEAR | «1900 год» |
| `end` задан | «с … по …» / «между … и …» |
| UNKNOWN | «дата неизвестна» (+ `original`, если есть) |
| `start` и `end` `null` | «дата не указана» |

Не показывай «1 января 1900» для точности YEAR: полное значение `start` — технический артефакт.
Не превращай `UNKNOWN` в приблизительную дату.

## Сравнение и вычисления
- Возраст/разница — по самой грубой из точностей, с диапазоном.
- Два события «в один день» утверждай только при точности DAY у обоих.
- Порядок событий определяй только если интервалы не пересекаются; иначе «порядок неизвестен».

## Календарь (вне дерева)
В России до 1 (14) февраля 1918 действовал юлианский календарь. Даты из метрических книг
часто даны по старому стилю. Если в `original` есть «ст. ст.»/«н. ст.», сохрани пометку.
Не пересчитывай стиль сам, если не указано, какой использован, — спроси или предупреди.
