# Навыки ассистента Genealogy Tree & Timeline

Назначение: чат-ассистент внутри продукта отвечает на свободные вопросы о генеалогическом проекте.

Ограничение среды: ассистенту desktop-чата доступны **14 read-only tools** (`get_project`, `get_tree_overview`, `search`, `get_person`, `get_event`, `get_ancestors`, `get_timeline`, `find_path`, `get_kinship`, `validate_project`, `list_sources`, `get_source`, `list_backups`, `get_current_date`). Кроме них — один опциональный write-инструмент `update_person`, доступный только при включённой настройке «Разрешить ассистенту редактировать». `list_projects` и `server_info` у него нет. Все навыки построены под это.

Структура: 1 базовый навык (`core`, загружается всегда) + 12 тематических (подгружаются по теме вопроса).

## Файлы

Один навык — один файл в этом каталоге. Имя файла без `.md` обязано совпадать с полем `name` во frontmatter. `core` — всегда включён; роутер добавляет не больше трёх тематических навыков.

Каждый файл начинается с frontmatter и продолжается телом навыка:

```markdown
---
name: find-person
description: Краткое описание, когда навык нужен.
---

# Заголовок

Инструкции для модели.
```

`name` и `description` обязательны и не могут быть пустыми. Файлы встраиваются в бинарник на этапе компиляции списком `include_str!` в `desktop/crates/chat/src/skills.rs`; чтения с диска во время работы нет. Этот README навыком не является и в каталог не встраивается.

## Маршрутизация вопросов

Триггеры роутера живут в `desktop/crates/chat/src/skills.rs` (константа `RULES`). Таблица ниже — человекочитаемое описание тех же правил; при изменении триггеров обновите и её.

| Вопрос пользователя (пример) | Навык |
|---|---|
| «Кто такой Иван Петров?», «найди бабушку Марию» | `find-person` |
| «Расскажи про деда», «что известно об Анне» | `person-profile` |
| «Кем мне приходится…», «были ли у него братья» | `family-relations` |
| «Что происходило в 1941», «хронология семьи», «сколько ему было лет» | `timeline-chronology` |
| «Кто жил в Саратове», «что связано с деревней X» | `place-research` |
| «Чем подтверждено», «какие есть документы» | `sources-evidence` |
| «Сколько людей в дереве», «с чего начать», «что заполнено плохо» | `tree-overview` |
| «Найди ошибки», «есть ли противоречия», «дубли» | `data-quality-audit` |
| «Как читать эту дату», «что значит precision» | `date-handling` |
| «Где искать дальше», «в каком архиве» | `research-guidance` |
| «Исправь опечатку в фамилии», «поменяй заметки», «поставь дату смерти» | `person-data-editing` |
| «Добавь человека», «удали», «создай связь/событие» | `edit-request-handoff` |

Вопрос может затрагивать несколько навыков — загружаются все нужные (до трёх тематических), `core` обязателен всегда. Если набор инструментов пуст, навыки в системный промпт не добавляются.
