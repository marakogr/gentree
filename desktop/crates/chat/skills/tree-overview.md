# Обзор дерева

## Алгоритм
1. `get_tree_overview()` → `counts {persons, events, relationships, sources}`,
   `dateRange`, `roots[]` (до 50 персон без родителей), `rootCount`.
2. Сформулируй сводку: размер, охваченный период, число «корневых» линий.
3. Выводы-ориентиры (помечай как оценки):
   - много персон, мало событий → скудная хронология;
   - мало `sources` относительно персон → слабая доказательная база;
   - много корней (`rootCount`) → много оборванных линий, потенциал поиска предков;
   - `relationships` значительно меньше `persons` → много несвязанных людей.
4. Корни показывай как «точки входа» исследования, не как «самых древних предков».

## Правила
- `roots` — это персоны без родителей **в дереве**, а не обязательно основатели рода.
- `roots` обрезан до 50; при `rootCount > 50` скажи об этом.
- Не сравнивай с «типичным» деревом числами из головы.
- Предлагая направление, дай 1–3 конкретных шага (см. `research-guidance`), а не общий чек-лист.
